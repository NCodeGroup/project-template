# Security Policy

## Report a Vulnerability

Report it privately: on the repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue or pull request for it. The report reaches the maintainer only, and the fix is discussed in a private security advisory until it is released.

Include what is affected (a script, a workflow template, a generated file), how to reproduce it, and what it lets an attacker do.

## Supported Versions

Only the newest tagged version gets fixes. A project made from the template moves to it with `.\.template\Update-Project.ps1`; the changelog section of the release says what changed.
