A Copilot session can't change the folder its shell starts in, so start every command with `Set-Location -LiteralPath '<plan folder>';`, give file tools absolute paths under `<plan folder>`, and search with `git -C '<plan folder>' grep` or by path, because a workspace search skips the ignored `.claude/worktrees/`. When you delegate to a subagent, give it `<plan folder>` and these rules, and tell it to work only there.
