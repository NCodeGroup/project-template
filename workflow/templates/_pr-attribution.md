Before you pass a title or a description to `gh` or `glab`, read it line by line and delete each line of agent attribution: a `Co-authored-by:` line that names an AI agent, such as Copilot or Claude, a `Claude-Session:` line, or a "Generated with" line that advertises an AI tool, such as Claude Code's. The `Commit attribution` check fails a pull request whose title or description holds one, because a merge can copy them into the commit on the default branch.
