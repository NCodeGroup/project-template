Before you pass a title or a description to `gh` or `glab`, read it line by line and delete each line of agent attribution: a `Co-authored-by:` line that names an AI agent, such as Copilot or Claude, a `Claude-Session:` line, a "Generated with" line that advertises an AI tool, such as Claude Code's, the "Generated by [Claude Code]" footer a session's GitHub tooling appends, or a line that holds only a `claude.ai/code/session_` link. The `Commit attribution` check fails a pull request whose title or description holds one, because a merge can copy them into the commit on the default branch.
