Before you pass a title or a description to `gh` or `glab`, read it line by line and delete each line of agent attribution, whichever AI agent, assistant or model it names: a `Co-authored-by:` line that names an AI agent or model (Copilot, Claude, Codex, Cursor, Devin, Gemini, Grok, GitLab Duo, aider, a local model or any other) or uses an agent's address, a session trailer such as `Claude-Session:`, `Agent-Logs-Url:` or `Amp-Thread-ID:`, a `Made-with:`, `Assisted-by:` or `Generated-by:` line that names an AI tool, a line that starts, after any symbols or underscores, with words such as "Generated with", "Generated by" or "Created by" and then an AI tool, such as the `_Generated by [Claude Code](…)_` footer a Claude Code cloud session appends, or a line that holds only a link to an agent's session or task, such as a `claude.ai/code/session_` or `chatgpt.com/codex/tasks/` link. Nothing checks for them afterwards, so this is the only place the workflow removes them.
