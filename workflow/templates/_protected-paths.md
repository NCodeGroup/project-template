A protected path is a file in a folder named `.github`, `.template`, `.claude`, `.githooks`, `.vscode` or `build`, at any depth, a file named `AGENTS.md`, `CLAUDE.md`, `.mcp.json`, `.copier-answers.yml`, `Makefile`, `Dockerfile` or `.npmrc`, a `*.props` or `*.targets` file, `global.json`, or a dependency manifest or lock file, such as `package.json`, `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `*.csproj`, `packages.lock.json`, `requirements.txt`, `pyproject.toml`, `poetry.lock`, `go.mod`, `go.sum`, `Cargo.toml` or `Cargo.lock`. These paths control CI, the template, agent instructions and configuration, the Landing section's gate, the build and the dependencies, and a bot's text can carry prompt injection from an issue or pull request, so a bot's finding never changes one.
