Read the issues each entry's issues are blocked by, as `gh api "repos/{owner}/{repo}/issues/<number>/dependencies/blocked_by?per_page=100&page=<n>"` lists them, each with its `number` and `state`; when a read fails, say so and count that issue as blocked by nothing. Leave out an entry, and say which open issue blocks it, when one of its issues is blocked by an open issue that is in neither that entry nor an entry ahead of it in the queue: it waits for work this run doesn't do. An entry blocked by an entry ahead of it keeps its place, and never runs ahead of that entry: it is planned only once that entry has landed and `finish-plan` has run for it. When that entry stops, or an issue it is blocked by is still open when its turn comes, stop it as Stop an Issue says, naming the blocker.
